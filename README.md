## 🌐 Cara Deploy ke Domain `ikzaazabd.site`

Website ini dibangun menggunakan standar web murni (HTML5, Modern CSS, ES Modules) tanpa memerlukan bundler/framework build step:

### Opsi 1: Vercel (Paling Mudah & Gratis)
1. Upload folder ini ke GitHub: `https://github.com/ikzaazabd/portfolio`
2. Buka [Vercel](https://vercel.com) -> New Project -> Import dari GitHub.
3. Di tab **Settings** -> **Domains**, masukkan domain Anda: `ikzaazabd.site`.
4. Tambahkan DNS A record / CNAME di registrar tempat Anda membeli domain. Selesai!

### Opsi 2: GitHub Pages (Gratis)
1. Push repository ke GitHub.
2. Buka repository -> **Settings** -> **Pages** -> pilih branch `main`.
3. Di bagian **Custom domain**, masukkan `ikzaazabd.site`.
