# Icon sources
- symbols/*.png: rendered from macOS NSImage(systemSymbolName:) / SF Symbols using AppKit.
- apps/photobooth.png, photos.png, music.png, siri.png, xcode.png: native installed macOS application icons, converted from their original AppIcon.icns / Xcode.icns resources.
- apps/github.svg, figma.svg, instagram.svg: brand marks distributed by Simple Icons 11.15.0 (https://github.com/simple-icons/simple-icons/tree/11.15.0/icons).
- LinkedIn contact mark: existing LinkedIn brand SVG.
